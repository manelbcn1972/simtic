# Lead OS (QA)

Implementación inicial para convertir alertas de correo de LinkedIn Sales Navigator en oportunidades revisables.

Clay se usa como fuente de technographics (stack tecnológico, tamaño y señales de cuenta) y se registra por evento como enriquecimiento independiente.

La migración se ha aplicado solo a la rama QA de Supabase. No hay despliegue a producción.
